## Retrieval & recommender work

- **[Netflix Catalog Search](https://github.com/NikosMav/netflix-catalog-search)**: BM25, dense, hybrid RRF and cross-encoder reranking over a Netflix title catalog; hybrid + rerank reaches nDCG@10 0.7185 on 28 author-labeled queries.
- **[SciFact Hybrid Retrieval](https://github.com/NikosMav/scifact-hybrid-retrieval)**: BM25, MiniLM and hybrid RRF on BEIR SciFact test; BM25 nDCG@10 0.676 against the published Anserini BM25 baseline of 0.679.
- **[MovieLens Recommender](https://github.com/NikosMav/movielens-recommender)**: staged recommender on MovieLens with a bootstrap-CI evaluation harness; item–item kNN reaches NDCG@10 0.120 on ml-1m.
